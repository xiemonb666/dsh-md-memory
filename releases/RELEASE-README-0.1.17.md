# dsh-md-memory 0.1.17

本版本修复动态后端能力探测导致的零输出预算问题。

## 安装

```powershell
npm install --legacy-peer-deps .\dsh-md-memory-0.1.17.tgz
```

安装后重启 DSH Desktop。当前会话的历史上下文窗口可能仍显示旧值；新建会话后会读取新的路由容量。
